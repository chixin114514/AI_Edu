# 慢行视频：自己修改与导出

## 先打开工程

Remotion 是用 React 编排视频的工具。本工程已经把常改的文字和参数做成可视化控件，不需要你先学习 React。手机内部的操作来自录屏，不能在视频编辑器中直接修改其中的按钮。

在 Mac 上双击同目录的 `打开预览.command`。终端窗口保持打开，在浏览器访问 http://localhost:3333，选择左侧 `ManxingDemo`。当前电脑已装好依赖。如果浏览器没有自动出现，手动打开网址即可。如果 3333 已经运行预览，直接使用已有页面，不必再启动一份。

也可以在终端执行：

```sh
cd '/Users/moln/Desktop/AI+/AI_Edu-demo-video/video-demo'
npm run studio -- --port=3333
```

首次换电脑需安装 Node.js，然后运行 `npm ci`；上述绝对路径只适用于当前电脑。Windows 使用终端命令，不使用 `.command` 文件。

## 不写代码：改文字、颜色、镜头幅度

1. 在 Studio 右上角打开侧栏（Mac 快捷键 `⌘J`），选 **Inspector → Default Props**（有些版本称为 Props）。
2. 展开相应字段，修改后画面会实时更新。空格播放/暂停，拖动下方时间轴预览。
3. 本机这版修改后会自动写回 `src/Root.tsx`，点击输入框外完成编辑。刷新页面检查是否保留；已经实测修改品牌名、刷新和恢复均可用。若其他版本显示磁盘保存按钮，再点击保存。
4. 点右上角 **Render**，选 H.264 / MP4，渲染当前参数。也可以双击 `导出视频.command`，它使用已经保存到源文件的参数。

| 字段 | 怎么改 |
| --- | --- |
| 品牌、英文名 | 控制开头 Logo 下方文字，以及左上角品牌名。品牌图形仍是慢行的标志。 |
| 主题色 | 填十六进制颜色，如 `#1f7a55`。影响 Logo、标题、背景形状和进度条，不改变录屏中 App 自身配色。 |
| 镜头幅度 | 推荐 `0.7`～`1.1`，默认 `1`；`0` 为固定全景。内部范围限制在 `0`～`1.3`。值越大推近越明显。 |
| 显示操作提示 | 开关左侧的“查看建议 · 保留原路线”等动作提示。 |
| 显示底部说明 | 控制示例数据说明，比赛演示建议保留。 |
| 副标题 | 左上角“体感自适应城市旅行智能体”。 |
| 章节 | 按顺序展开，改“标签”“标题上行”“标题下行”“说明”。标题每行建议 6～9 个汉字。说明建议两行；若输入框不支持换行，切到 JSON，用 `\n` 分隔两行。 |

**时间的计算：** 工程共 45 秒、60fps，前 2.4 秒是 Logo 开场。章节与镜头配置中的秒数从录屏开始计时，例如“开始秒 5.8”对应成片第 **8.2 秒**，也就是第 **492 帧**。修改章节时间时保持顺序相连，结束时间大于开始时间；录屏部分结束于 42.6 秒。不要只改总时长，否则可能截断操作。

## 一个具体练习

在 Props → 章节 → 第 1 项，把“标题下行”由“从你开始。”改成“按喜好出发。”，把“镜头幅度”改成 `0.85`。拖到成片第 5 秒看文字，再拖到第 27 秒看确认调整的特写。确认喜欢后保存并 Render。

首次建议用 Studio 的 Render 直接导出；这样使用的就是当前面板参数。命令导出依赖源文件已保存。每次命令导出会覆盖 `out/manxing-demo-45s.mp4`，想保留旧版请先单独复制或改输出文件名。

## 改镜头与动画：改哪个文件

- `src/Root.tsx`：面板参数和输出规格。`defaultProps` 保持直接写在 Composition 中，才能让 Studio 写回设置。
- `src/camera.ts`：镜头关键帧。`s` 是录屏秒数；`zoom` 是缩放；`x` 是手机中心横坐标；`focusY` 是录屏里要看的位置（0～860）；`screenY` 是把它放到成片的哪个纵坐标。表格按秒数递增，不要重复秒数。
- `src/video.tsx`：Logo 动画、字体、布局、背景、操作提示。`hints` 中可改操作提示的文字与时刻。
- `public/interaction.mp4`：连续操作素材。素材只挂载一次，字幕改变不会重新开始播放。

例如，要让“接受调整”特写稍微轻一点，将 `camera.ts` 中 `s:23.8` 和 `s:26.5` 两行的 `zoom:1.45` 都改为 `zoom:1.3`，保留前后的缓动。做完先检查按钮是否仍在画面内，再导出。

Logo 采用本项目标志的 SVG 路径；若更换真正的 Logo 图形，在 `video.tsx` 的 `Mark` 中替换 SVG。修改品牌字段只会改字，不会自动生成另一个图标。

## 更换录屏

新素材放入 `public/` 并在 `OffthreadVideo` 中改文件名。务必逐项校准章节、操作提示和镜头时间。当前素材为 430×860 CSS 像素，放大会受到原素材清晰度限制；想提高细节，需重新录制更高实际像素的视频，仅改变导出分辨率不会增加细节。

当前版本保留录屏前 42.6 秒（全部关键操作完成，裁短片尾静置），加 2.4 秒 Logo 后为 45 秒，没有加速点击或剪断操作。无配音与音乐，便于插入比赛总片统一混音。

## 出问题时

- 改完文字被裁切：缩短每行，或到 `video.tsx` 调整字号；不要把大段话塞进两行标题。
- 预览卡顿：浏览器实时预览不等于最终渲染；先导出一个 MP4 检查。正式输出为 60fps。
- 双击脚本被 macOS 拦截：使用上方终端命令启动，无需更改系统安全设置。
- 中文缺字或换行不同：本机用 PingFang SC，其他系统需安装有授权的中文字体后核对画面。

官方参考：[可视化编辑 Props](https://www.remotion.dev/docs/visual-editing)、[Composition 参数](https://www.remotion.dev/docs/composition)。
