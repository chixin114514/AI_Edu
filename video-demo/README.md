# 慢行 45 秒连续操作演示动画

Remotion 工程，输出 1920×1080、60fps、45 秒 H.264 MP4。无配音、无背景音乐，便于插入比赛总视频统一混音。2.4 秒 Logo 开场、浅色背景、品牌绿色、连续操作录屏、重点区域推近和分层文字动画。

双击 `打开预览.command` 开始编辑；双击 `导出视频.command` 导出。详细步骤见 [自己修改视频](./自己修改视频.md)，包含实际测试过的 Inspector → Default Props 可视化编辑、自动保存与导出流程。

主体是同一段真实应用连续录屏，不使用页面截图轮播。选偏好、生成行程、查看详情、开始漫游、疲劳反馈后保留原路线、用餐反馈后接受调整、写日记、打卡和结束回顾均通过应用原有按钮完成。只有指针圆点属于录制标注，未修改产品业务行为、接口返回或数据。

## 本地预览与导出

```sh
cd video-demo
npm ci
npx remotion browser ensure
npm run studio
npm run check
npm run render
```

导出位置：`out/manxing-demo-45s.mp4`。`out/` 与依赖已忽略，不随 Git 提交。`public/interaction.mp4` 是合成所需的已裁边录屏素材，随工程保存，克隆后可以直接渲染。锁定 Remotion 4.0.535。

## 时间与画面

下表为录屏时间；成片时间需加 2.4 秒 Logo 开场。成片使用素材前 42.6 秒，缩短原版片尾静置，保留全部关键操作，总长仍为 45 秒。

| 时间 | 连续操作 | 旁注主题 |
| --- | --- | --- |
| 0–5.8 秒 | 选择建筑兴趣，浏览设置并生成行程 | 为自己规划 |
| 5.8–14.7 秒 | 滚动行程、查看详情、开始漫游并确认授权 | 看清行程 |
| 14.7–22.5 秒 | 主动反馈有点累、查看建议、保留原路线 | 说出感受 |
| 22.5–28.8 秒 | 反馈想吃饭、查看变化、接受调整 | 由你决定 |
| 28.8–39.2 秒 | 写入示例日记、保存、打卡和结束 | 记录沿途 |
| 39.2–42.6 秒 | 滚动手记，回看事件与日记 | 完整流程回顾 |

片中数据来自明确标识的演示模式，不是真实旅行、传感器实测或教学效果证据。未接入真实地图、模型服务和心率设备；使用手动体感反馈。演示建议如实显示时间与距离的取舍，不承诺一定减少步行量。文字日记明确注明“示例记录”。

## 录屏来源及复录

应用来源：本仓库 `f59fea0a12af0ddbd5fbadbcba1bbe3ae8ff2868`，2026-10-13 的 master。未改变 `public/`、`server/`、移动端或 Apple Watch 工程。

在仓库根目录启动一个独立的演示实例，避免使用个人行程或含密钥的环境文件：

```sh
PORT=3218 HOST=127.0.0.1 DATA_MODE=demo node server/index.js
```

`scripts/browser.json` 为录制视口配置，`scripts/record-flow.js` 是 Playwright CLI 的 `run-code --filename` 脚本。它应在全新浏览器会话的规划页运行；开始录制前滚动到 200px，并确保“建筑”尚未选中。录制器必须在运行脚本之前成功启动，完成后检查实际输出文件，而不能仅依赖 CLI 的链接提示。

本次使用 Playwright CLI 1.64.0 alpha，录像 60fps。该录制器使用 CSS 像素采集，设置 860×1720 输出时将完整 430×860 页面放在左上角，其余区域为填充。素材只裁去填充并去除开录前的 0.7 秒准备时间，保留连续的 45 秒操作，没有重新拼接页面或改变操作速度。复录必须先检查首尾和帧尺寸，不能盲目复用这一裁边参数。

录制依赖 Playwright 对应版本的 FFmpeg；安装另一版 FFmpeg 不会自动满足该版本的缓存路径。可用 CLI 所用的 `playwright-core/cli.js install ffmpeg` 安装匹配版本。

## 调整方式

- `src/Root.tsx`：Studio 可编辑的品牌、颜色、章节文案、镜头幅度，以及输出规格。
- `src/video.tsx`：Logo 开场、布局、分层文字与动作提示。
- `src/camera.ts`：推近、回拉与对焦位置的关键帧（录屏秒数）。
- `src/index.tsx`：注册入口。
- `public/interaction.mp4`：同一条连续操作素材。替换时应同步检查字幕和点击时刻。
- 中文字体使用本机 PingFang SC 或 Arial Unicode MS。跨平台渲染需提供有授权的中文字体并核对换行；工程不分发系统字体文件。

## 验证

本次运行应用 `npm run check`、完整 `npm test` 均通过；动画工程 TypeScript 检查通过。录屏结尾通过真实应用显示 1 次接受、1 次保留、1 次打卡和 1 条示例日记。已检查详情、建议、日记输入及回顾画面。

输出需通过 ffprobe 核对 1920×1080、60fps、2700 帧、45 秒，并检查无解码错误。没有编造地图数据或传感器读数；未配置地图导致的预览接口 503 属于已知演示环境限制，不作为真实服务验证结果。
